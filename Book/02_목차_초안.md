# 목차 초안 — Book-forge로 읽는 AI 에이전트와 Harness Engineering

**총 4개 파트, 15개 챕터 + 부록 2종.** 모든 챕터는 Book-forge(`818843d`) 또는 Agent-Evaluator(`d65889f`) 소스 코드를 직접 인용한다 — 가상의 예제 코드를 쓰지 않는다. 부록 A(용어집)는 코드 인용이 아니라 일반 개념 정의, 부록 B(업계 동향)는 이 책 유일하게 외부 자료를 인용하는 명시적 예외다. 그 외 종합 정리 성격의 내용(에이전트 전체 인벤토리, Config 사용 현황, 품질 검증 축 통합, AST 인덱싱 상세)은 본문 챕터와 맺음말에 흡수돼 있다 — 본문과 부록을 오가며 같은 내용을 두 번 읽지 않도록, 각 개념이 처음(그리고 유일하게) 등장하는 자리에서 완결시켰다.
